# Altas Horas Controle

PWA instalável para iPhone e Android.

## Instalação
1. Publique esta pasta em um endereço HTTPS.
2. iPhone/Safari: Compartilhar → Adicionar à Tela de Início.
3. Android/Chrome: abra o endereço e toque em Instalar aplicativo.
